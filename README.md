# PonteAPlomo

Material de clase de **Manuel Lería Sánchez** para el módulo 0568 *Instalaciones en Edificación*: simuladores interactivos de fontanería (agua fría, presión), agua caliente sanitaria y, más adelante, saneamiento.

Sitio: <https://ponteaplomo.es>

Este repositorio solo contiene las páginas ya compiladas que se publican en el sitio.
